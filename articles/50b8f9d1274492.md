# はじめに

[前回の記事](https://zenn.dev/e_kaikei/articles/8aa3bebbe4ce91)で、WASMを活用したリバースプロキシ・APIゲートウェイである「Plecto」あらため「Plecto Proxy」の思想や選択、設計原則について記述しました。

Plecto Proxyのリポジトリはこちら☟

https://github.com/Kaikei-e/PlectoProxy

今回はTinyGoをwasip2を使って、Plecto Proxyでのカスタムフィルタの記述を可能にしたので。その記録です。

## WASI 0.3およびwit-bindgenとTinyGoとの関係

本題に入る前に用語を整理します。APIゲートウェイのカスタムフィルタについて詳しく記載したいので、なるべく短くに記述します。

<br>

`TinyGo`

- Goをある制約下（後述）をターゲットにコンパイルするLLVMベースの代替コンパイラです
- 「ある制約下」とは、バイナリサイズを極端に小さく要求したり、あるいは求められたりする環境で、標準ツールチェインとは別のサブセットをLLVMで出力します
- マイコンやWebAssemblyをターゲットとして利用されることが多いようです

### wasi2p, wit-bindgenとTinyGoの関わり

本題のWASI 0.3とwit-bindgenとTinyGoとの関わりですが、前述の[はじめに](#はじめに)の項で記述した際には、wasi**p2**と記述しました。

ここで前回の記事で記載した「Plecto Proxy」の弱点である、「WASMの成熟を待つ必要がある」という点が絡んできます。
wasip2(=WASI0.2)は`wasi preview 2`の略であり、まだプレビュー版です。wasi**p3**(WASI 0.3)も出ていますが、p2からp3でComponent ModelのCanonical ABIが非同期処理の扱いを一級市民へと置くと同時に変更したからです。そのため、ホストランタイムである `wasmtime`で対応・実装が進んでいても、ゲスト側である言語、例えばGo言語などは現段階では、標準コンパイラでGOOS=wasip3自体が提案段階にとどまっています。
WASI1.0への到達は2026年内を目指して開発をされているのですが、Plecto ProxyではWASI 0.3で非同期処理の扱いが一級市民へと変わったことを受けて、プレビュー版でも先取りをして実装を進めています。そのため、前述のwasip`0.2`と`0.3`のズレが生じます。

## TinyGOとカスタムフィルター生成までのフロー

```mermaid
WIT定義 (.wit)
   ↓ wit-bindgen-go generate
生成されたGoバインディング（cmパッケージに依存）
   ↓ 手書きのGoコードから呼ぶ/実装する
tinygo build -target=wasip2
   ↓
Wasmコンポーネント（.wasm）
```

## では、なぜwasi**p2**でTinyGoを入れるのか？

1. TinyGoサポートにより、Plecto Proxyのカスタムフィルターを**Go言語で記述できる**ようになり間口が広がるため
2. 多言語カスタムフィルターを目的としている`Plecto Proxy`は、Go言語側のwasi0.3対応を待たずに導入すべきと判断したから

理由1に関しては、理由2ともやや重なるのですが、このPlecto Proxyの間口を広げたかったからです。Goは自分も好きで良く使う言語です。
また言語の人口も多いと思っているので、「ポリグロットなカスタムフィルタ記述が可能」と標榜する以上、Plecto Proxyが現時点でサポートをTier Bに据えている言語（Go, Pythonなど）でも取り入れてみてどうなるか関心がありました。

理由2に関しては、不確定な要素であるGo側のWASI 0.3対応を待つよりも、非同期の扱いが異なるTinyGoでもまずはフィルターを書ける機能を実装をしておき、そこから改善やGo側のWASI 0.3のサポートを待った方が良いと判断したためです。

以下ざっとコードを見ていきたいと思います。

渡している権限は次の6つだけです。
これがインターフェースで
- ログ
- 時刻
- KeyValue
- カウンター
- レート制限
- 設定値

```wrold.wit
package plecto:filter@0.1.0;

interface types {
    record header {
        name: string,
        value: string,
    }
    record http-request {
        method: string,
        path: string,
        authority: string,
        scheme: string,
        headers: list<header>,
    }
    record http-response {
        status: u16,
        headers: list<header>,
        body: list<u8>,
    }
    record request-edit {
        set-headers: list<header>,
        remove-headers: list<string>,
    }
    record response-edit {
        set-status: option<u16>,
        set-headers: list<header>,
        remove-headers: list<string>,
    }
    variant request-decision {
        %continue,
        modified(request-edit),
        short-circuit(http-response),
    }
    variant response-decision {
        %continue,
        modified(response-edit),
    }
    variant request-body-decision {
        %continue(list<u8>),
        short-circuit(http-response),
    }
}

interface host-log {
    enum level { trace, debug, info, warn, error }
    log: func(level: level, message: string);
}

interface host-clock {
    now-ms: func() -> u64;
}

interface host-kv {
    get: func(key: string) -> option<list<u8>>;
    set: func(key: string, value: list<u8>);
    delete: func(key: string);
}

interface host-counter {
    increment: func(key: string, delta: s64) -> s64;
    get: func(key: string) -> s64;
}

interface host-ratelimit {
    record acquire {
        allowed: bool,
        remaining: u64,
        retry-after-ms: u64,
    }
    try-acquire: func(key: string, cost: u64) -> acquire;
}

interface host-config {
    get: func(key: string) -> option<string>;
}

world filter-body-go {
    use types.{http-request, http-response, request-decision, response-decision, request-body-decision};

    import host-log;
    import host-clock;
    import host-kv;
    import host-counter;
    import host-ratelimit;
    import host-config;
    include wasi:cli/imports@0.2.0;

    export init: func();
    export on-request: func(req: http-request) -> request-decision;
    export on-request-body: func(body: list<u8>) -> request-body-decision;
    export on-response: func(resp: http-response) -> response-decision;
}

```
